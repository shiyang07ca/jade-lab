# 学习画像

跨主题背景和偏好由 Agent 读取；修改需用户逐项确认。具体主题的掌握程度、当前进度和证据由主题目录维护。

## 背景

- 有 Python/Django 后端经验，理解 HTTP 和一般 SQL 概念。
- 关注工程原理，希望理解成立条件并能够独立应用，不以读完材料或运行教师代码代替掌握。

## 偏好

- 默认中文；必要术语首次出现时解释含义，并保留准确标识符。
- 讲清原理、因果和成立条件，按当前理解逐步展开。
- 先交代操作对象与明确的第一步，一次推进一个有意义的问题。
- 通过代码运行和真实反馈检验理解，正确应用后及时推进。
- 可以自由追问、探索、跳过练习或直接索取答案，练习不是继续学习的准入条件。
- 不固定学习时间；Agent 保存必要状态和重要证据，不要求另写总结或管理进度。
