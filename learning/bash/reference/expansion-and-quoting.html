变量展开与引用速查

可打印的快速参考 · ← 返回第 4 课

变量赋值

写法说明
VAR=value 基本赋值，等号两边不能有空格 必须记住
VAR="value with spaces" 含空格的值必须加引号 必须记住
VAR='literal $HOME' 单引号不展开变量，值是字面量 常用
VAR=$(command) 命令替换——把命令的 stdout 赋给变量 必须记住
export VAR=value 导出为环境变量，子进程可见 常用
local VAR=value 函数内局部变量（只能在函数内使用） 常用
readonly VAR=value 只读变量，不可修改 进阶

引用规则对照

写法变量展开命令替换单词分割通配展开典型用途
'...' 单引号 ❌❌❌❌ 需要绝对字面量时——文本里恰巧有 $、`、\ 等特殊字符
"..." 双引号 ✅✅❌❌ 默认选择——展开变量但不破坏结构
无引号 ✅✅✅✅ 极少使用——只有明确需要分割或通配时才不加引号
黄金法则：变量引用一律加双引号。写 "$VAR"，永远不写裸的 $VAR。

基本展开语法

语法含义示例（VAR=hello）
$VAR 读取变量值 echo $VAR → hello
${VAR} 读取变量值（大括号定界） echo ${VAR}_world → hello_world
${#VAR} 变量值的长度（字符数） echo ${#VAR} → 5

参数展开：默认值 / 条件

语法VAR 已设置且非空时VAR 未设置或为空时会修改 VAR 吗？
${VAR:-word} 返回 VAR 的值 返回 word 不修改
${VAR:=word} 返回 VAR 的值 把 VAR 设为 word，再返回 会修改
${VAR:?message} 返回 VAR 的值 打印 message 到 stderr，退出脚本 不修改，但退出
${VAR:+word} 返回 word（不是 VAR！） 返回空 不修改

实际用法：

DEPLOY_ENV="${1:-production}"     # 第一个参数没给就用 production
BACKUP_DIR="${BACKUP_DIR:=/tmp}"  # 没设置就用 /tmp，并赋值
: "${API_KEY:?必须设置 API_KEY}"   # 没设置就报错退出（: 是 no-op 命令）

参数展开：字符串操作

语法含义示例（FILE=/opt/app/config.yml）
${VAR#pattern} 从开头去掉最短匹配 ${FILE#*/} → opt/app/config.yml
${VAR##pattern} 从开头去掉最长匹配 ${FILE##*/} → config.yml
${VAR%pattern} 从末尾去掉最短匹配 ${FILE%.*} → /opt/app/config
${VAR%%pattern} 从末尾去掉最长匹配 ${FILE%%.*} → /opt/app/config（同上，因为只有一个点）
${VAR:offset} 从 offset 开始截取子串 ${FILE:5} → app/config.yml
${VAR:offset:length} 从 offset 截取指定长度 ${FILE:0:4} → /opt
${VAR/old/new} 替换第一个匹配 ${FILE/config/conf} → /opt/app/conf.yml
${VAR//old/new} 替换所有匹配 ${VAR//\//_} → _opt_app_config.yml
${VAR/#old/new} 只在开头匹配时替换 ${FILE/#\/opt/\/usr} → /usr/app/config.yml
${VAR/%old/new} 只在结尾匹配时替换 ${FILE/%yml/yaml} → /opt/app/config.yaml
记忆口诀：# 在左边（从开头删）、% 在右边（从末尾删）；单个 #/% 是最短匹配（lazy）、双个是最长匹配（greedy）。/ 是替换，和 sed 类似——一个斜杠替换首个，两个替换全部。

特殊变量速查

变量含义常见用法
$? 上一条命令的退出码（0=成功） if [ $? -ne 0 ]; then exit 1; fi
$$ 当前 Shell 的进程 ID echo $$ > /var/run/app.pid
$! 最后一个后台进程的 PID myapp & PID=$!
$0 脚本或 Shell 自身的名称 echo "Usage: $0 <file>"
$1 ~ $9 第 1~9 个位置参数 TARGET="$1"
${10} 第 10+ 个位置参数（必须花括号） TENTH="${10}"
$# 位置参数个数 [ $# -eq 0 ] && { echo "需要参数"; exit 1; }
$@ 所有位置参数（每个独立） for arg in "$@"; do ...; done
$* 所有位置参数（合并为一个） 几乎不用，永远用 "$@"
$- 当前 Shell 选项标志 echo $- → himBHs（调试用）
$_ 上一条命令的最后一个参数 mkdir /long/path && cd $_

常见错误与修复

错误写法 ❌问题正确写法 ✅
VAR = value 等号有空格 VAR=value
echo $FILE 未加引号，单词分割 echo "$FILE"
MSG='Hello $USER' 单引号不展开变量 MSG="Hello $USER"
if [ $? == 0 ] 含义反了（0=成功） if [ $? -eq 0 ]
RESULT=`date` 旧式反引号语法 RESULT=$(date)
APP_HOME_logs=$APP_HOME/logs Bash 把 HOME_logs 当变量名 APP_HOME_logs=${APP_HOME}/logs
for f in $* 参数含空格会分裂 for f in "$@"
echo ${11} $11 被解析为 ${1}1 echo "${11}"（第 11 个参数必须花括号）
