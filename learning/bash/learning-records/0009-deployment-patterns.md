# 掌握了部署脚本常见模式

用户理解了真实部署脚本的 8 个经典模式：结构化日志（带时间戳/级别、tee 双写）、锁文件（flock -n 防并发）、健康检查等待（轮询+超时）、原子写入（mktemp + mv）、备份回滚（tar + trap EXIT 自动恢复）、通知钩子（curl webhook）、配置加载（优先级链：环境变量 > .env > 默认值）、符号链接部署（releases/ + current → 原子切换秒级回滚）。能将这些模式关联到前 8 课的具体知识点。通过了 4 道自检题。

**Implications**：用户现在可以读懂大多数生产级部署脚本的骨架结构。第 10 课引入进程管理后，可以理解部署脚本中的后台启停、信号处理和多进程协调。
