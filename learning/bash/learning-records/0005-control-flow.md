# 掌握了控制流

用户理解了 Bash 中 `if` 的本质——它判断命令的退出码而非布尔值。掌握了 `test`/`[ ]`/`[[ ]]` 三种测试写法及其区别（`[[ ]]` 是 Bash 增强版，更安全推荐），熟悉了常用文件测试（`-f`、`-d`、`-x`）、字符串比较（`=`、`-z`）和数值比较（`-eq`、`-lt` 等）。能使用 `for` 遍历词列表（包括 `{1..10}` 范围、文件通配、命令输出），`while`/`until` 实现条件等待，`case` 做 glob 模式多路分支，以及 `&&`/`||` 短路运算符的用法和陷阱。通过了 4 道自检题。

**Implications**：用户现在具备编写有逻辑判断和循环的脚本的基础能力。第 6 课引入函数后，可以将这些控制流封装成可复用的函数，写出结构化的脚本。后续涉及 `set -e`、`trap`、脚本调试时，控制流和退出码的理解是关键前提。
