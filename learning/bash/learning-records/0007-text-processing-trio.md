# 掌握了文本处理三剑客

用户理解了 grep（按模式筛选行、支持基本/扩展/Perl 三种正则）、sed（流编辑器，80% 场景用 `s/old/new/` 替换命令，`-i` 原地修改）和 awk（按列处理数据，`$1`/`$2`/`$NF` 引用各列，`-F` 指定分隔符）的核心用法，以及三者与 `sort | uniq -c | sort -rn | head` 组合成的经典日志分析管道链。能区分三者的适用场景：grep 筛选行、sed 改内容、awk 提取列。通过了 4 道自检题。

**Implications**：用户现在可以读懂部署脚本里大多数 grep/sed/awk 命令，并能组合出简单的日志分析管道。第 8 课引入错误处理（set -e、trap）后，可以将文本处理嵌入到可靠的、带错误处理的脚本中。后续涉及 jq 的 JSON 处理课可以类比 awk（都是"从结构化文本中提取字段"）。
