# 后台任务状态汇总

用户能区分异步命令的即时状态、`$!` 保存的后台进程 PID 与指定 PID 的 `wait` 最终状态，并能使用同一数组索引保持
任务名称和 PID 的对应关系。用户实现了 collect-all 汇总函数：逐项等待所有任务，成功结果写 stdout，失败结果连同
原始状态写 stderr，批次只用 0/1 表达是否含失败，不因单项失败提前返回。

实现已在 GNU Bash 3.2.57 和课程固定的 GNU Bash 5.3.15 中通过全部成功、单项返回 7、完成顺序变化三个受控场景。
分离观察实际完成事件、stdout 和 stderr 后，任务身份与状态保持对应。
