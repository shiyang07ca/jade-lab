# 掌握了函数与脚本结构

用户理解了 Bash 函数的定义语法（`name() { ... }`）、函数内部独立的位置参数（`$1`/`$2`/`$@` 由调用者传入）、`local` 限定变量作用域的必要性，以及函数的两种"返回"机制——`return N` 返回退出码（用于判断成功/失败）、`echo` + `$(func)` 捕获 stdout（用于获取字符串数据）。掌握了标准脚本的 6 层骨架结构（Shebang → set -e → 常量 → 工具函数 → 业务函数 → `main "$@"`），以及 `./script`（执行，新进程）和 `. script`（引入，当前 Shell）的本质区别。通过了 4 道自检题。

**Implications**：用户现在可以识别和理解专业 Bash 脚本的结构模式，不会在函数参数传递和变量作用域上踩坑。这是从"能写语法"到"会写有结构的脚本"的关键转折。第 7 课引入 grep/sed/awk 后，可以在业务函数中嵌入文本处理逻辑（如 `grep ERROR | awk '{print $3}' | sort | uniq -c`），完成日志分析和数据提取。
