# 掌握了进程管理

用户理解了后台进程（`cmd &`）的启动与 `$!` PID 获取、`wait` 等待机制（等单个/等全部，并行部署的核心）。掌握了子 Shell `( )` 的环境隔离（cd、变量不泄漏）与大括号 `{ }` 在当前 Shell 执行的区别，以及管道中每段都在子 Shell 运行的陷阱。熟悉了信号体系（SIGTERM 可捕获优雅退出、SIGKILL 强制不可捕获、SIGINT 来自 Ctrl+C、SIGHUP 来自终端关闭），以及终止进程的正确顺序（先 TERM 等待后 KILL）。能使用 trap 同时处理 EXIT/INT/TERM 多种信号，并理解了 nohup/disown 让进程在终端关闭后继续存活的机制。通过了 4 道自检题。

**Implications**：用户可以编写带超时控制、PID 文件管理、并行任务协调的脚本。第 11 课引入 curl + jq 后，可以将进程管理（后台健康检查轮询）和 API 交互结合起来。
