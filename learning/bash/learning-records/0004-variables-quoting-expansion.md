# 掌握了变量、引用与展开

用户理解了 Bash 的展开（expansion）流水线——变量替换和命令替换发生在命令执行之前。掌握了变量赋值的三条铁律（等号无空格、含空格加引号、变量名限制）、`$VAR` vs `${VAR}` 的区别、单引号（全字面）/双引号（展开但保护结构）/无引号（危险）的引用规则、`$(...)` 命令替换的现代写法，以及 `$?`、`$0`-`$9`、`$@`、`$#` 等特殊变量。认可了"变量引用永远加双引号"的黄金法则。通过了 4 道自检题。

**Implications**：用户现在能理解部署脚本中 `${APP_HOME}/logs`、`NOW=$(date)`、`"$@"` 等写法。第 5 课引入控制流后，可以结合变量写出有判断和循环的脚本。后续涉及函数参数传递时可直接引用 `$@` 和 `$#` 概念。
