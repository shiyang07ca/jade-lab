文件系统操作

告别「只会 ls 和 cat」——掌握日常文件操作的核心命令

部署脚本里充满了文件操作：创建目录、复制配置、查看日志、检查权限。这节课覆盖的命令是你未来读脚本时最常见的「动词」。

1. 你真的会用 ls 吗？

你已经知道 ls 列出文件名。但 ls 的真正威力在它的选项里。四个最常用的：

ls -l        # long: 详细信息（权限、大小、修改时间）
drwxr-xr-x  5 alice  staff  160 Jul 22 10:51 lessons
-rw-r--r--  1 alice  staff  2048 Jul 22 11:20 deploy.sh

ls -a        # all: 显示隐藏文件（以 . 开头的文件）
.           ..          .git        .gitignore  README.md

ls -lh       # human-readable: 文件大小用 K/M/G 显示
-rw-r--r--  1 alice  staff  2.0K Jul 22 11:20 deploy.sh

ls -lt       # time: 按修改时间排序，最新的在最前面
-rw-r--r--  1 alice  staff  2.0K Jul 22 11:20 deploy.sh
drwxr-xr-x  5 alice  staff   160 Jul 22 10:51 lessons

多数彼此独立的短选项可以组合；如果选项语义冲突，顺序可能影响最终行为，应以目标实现的手册为准：

ls -ltrh     # 详细信息 + 按时间排序 + 反向（最旧的在最前面） + 人类可读
ls -la       # 详细信息 + 包含隐藏文件
ls -l 输出解读：第一列 drwxr-xr-x 里，第一个字符 d 表示目录（- 表示普通文件，l 表示符号链接）。后面九个字符是权限，分成 user/group/other 三组，每组 r=读 w=写 x=执行。这节课后我们会深入权限。

2. 导航：在目录间快速移动

pwd          # 打印当前所在目录（print working directory）
/Users/alice/code/jade-lab

cd /tmp      # 去 /tmp
cd -         # 回到刚才的目录（相当于遥控器上的「返回」键）
/Users/alice/code/jade-lab

cd           # 不带参数 = 回 home 目录
cd ..        # 去上级目录
cd ../..     # 上两级
cd - 只记住「上一个」目录，因此可以在两个目录之间反复切换，但不能保存完整历史。如果需要管理多个目录，用 Bash 的 pushd、popd 和 dirs。

3. 查看文件内容：不止 cat

命令 用途 典型场景
cat f 一次性输出全部内容 文件很短时、或要把它传给下一个命令
less f 分页浏览，上下翻动 阅读部署脚本、日志文件（q 退出，/ 搜索）
head f 只看前 10 行 快速确认文件开头长什么样
tail f 只看末尾 10 行 检查最新日志
tail -f f 实时追踪文件末尾新增内容 实时监控日志输出（Ctrl+C 停止） 
head -n 20 deploy.sh          # 看前 20 行
tail -n 3 /var/log/nginx.log  # 看最后 3 条日志
tail -f /var/log/app.log    # 一直盯着日志，有新内容立刻显示

less deploy.sh              # 翻页浏览脚本
# less 内部快捷键：
#   j/k 或 ↓/↑ — 上下一行
#   f/b 或 PgDn/PgUp — 上下翻页
#   /关键字 — 搜索
#   n — 下一个匹配
#   q — 退出
tail -f 适合交互观察追加中的日志。部署出问题时，可以在另一个终端运行 tail -f /var/log/app.log 再触发请求；自动监控仍应使用能处理轮转、断线和结构化事件的工具。

4. 创建和删除

mkdir newdir              # 创建目录
mkdir -p a/b/c/d          # 递归创建多层目录（不会因为父目录不存在报错）

touch empty.txt           # 创建空文件 / 更新已有文件的修改时间
touch deploy.sh           # ⚠️ 不会清空内容，只更新修改时间

rm file.txt               # 删除文件
rm -r mydir               # 递归删除目录（⚠️ 不可逆）
rm -rf mydir              # 强制删除，不提示确认（⚠️⚠️ 极度危险）
rmdir emptydir            # 只能删空目录，安全但很少用
rm 是外部文件工具，不是 Bash 语法。-r 会递归删除，-f 还会抑制部分诊断。自动化删除前应解析精确目标，拒绝空值、根目录和意外父目录，引用参数并使用 -- 结束选项；“变量不为空”本身不足以证明目标安全。

5. 复制和移动

cp source.txt dest.txt     # 复制文件
cp -R srcdir/ destdir/     # 按 POSIX -R 递归复制目录
cp file1 file2 file3 dir/  # 把多个文件复制到同一个目录

mv oldname newname         # 在同一文件系统内通常由 rename 完成
mv file.txt /tmp/          # 移动文件到 /tmp
mv file1 file2 dir/        # 移动多个文件到目录
cp 和 mv 默认都可能覆盖已有目标。同一文件系统内的 mv 通常是重命名； 跨文件系统移动可能退化为复制后删除，因此性能、原子性和失败状态不同。不要把 -n、-b 当作跨平台接口：GNU 与 BSD/macOS 实现的选项和细节并不完全相同。自动化脚本应先确定目标平台， 再使用该平台手册支持的选项，并用临时目录验证覆盖行为。

6. 读懂权限

ls -l deploy.sh
-rwxr-xr--  1 alice  staff  2048 Jul 22 11:20 deploy.sh
 │││││││││
 │└┬┘└┬┘└┬┘    r=读  w=写  x=执行  -=没有
 │ │  │  │
 │ │  │  └── other（其他人）   r--  = 只能读
 │ │  └───── group（同组用户）  r-x  = 可读、可执行，不可写
 │ └──────── user（文件拥有者）  rwx  = 可读、可写、可执行
 └────────── 文件类型：- 普通文件，d 目录，l 符号链接

修改权限用 chmod：

chmod u+x deploy.sh         # 给文件拥有者加执行权限
chmod 755 deploy.sh         # 数字模式：user=rwx, group=r-x, other=r-x
chmod 600 secret.key         # 只授予 owner 读写；是否满足敏感文件要求还取决于目录、ACL 等
数字 01234567
权限 -----x-w--wxr--r-xrw-rwx

记法：读=4、写=2、执行=1。加在一起就是你要的数字。755 = 4+2+1, 4+0+1, 4+0+1 = rwx, r-x, r-x。

动手练习（5 分钟）

在你的终端里完成以下操作，每个命令都亲自敲一遍：

从仓库根目录运行，所有练习状态留在被 Git 忽略的 .scratch/：

mkdir -p .scratch/bash-course/files/logs
cd .scratch/bash-course/files
printf '%s\n' '这是第一行' > README.md
printf '%s\n' '#!/usr/bin/env bash' 'printf "hello\n"' > hello.sh
printf '%s\n' '错误日志内容' > logs/error.log
ls -lR                                           # 递归列出所有文件
head -n 1 README.md                              # 看第一行
chmod u+x hello.sh                               # 给脚本拥有者加执行权限
ls -l hello.sh                                   # 确认权限已变
./hello.sh
less README.md                                   # 翻页浏览（q 退出）
cd -                                            # 回到之前的目录

7. 看一眼文件类型

file deploy.sh
deploy.sh: Bourne-Again shell script text executable, ASCII text

file myphoto.png
myphoto.png: PNG image data, 1920 x 1080, 8-bit/color RGB

file unknown.bin
unknown.bin: ELF 64-bit LSB executable, x86-64

file 不只看扩展名，而是结合文件内容、magic 数据库等规则判断类型。遇到不认识的文件时可先用它检查，但不要把识别结果当作安全审计。

快速自检

Q1: 你想查看一个 2000 行的日志文件的最后 50 行，用什么命令？

cat log.txt | last 50 tail -n 50 log.txt head -n 50 log.txt

Q2: rmdir mydir 报错 "Directory not empty"。你检查内容并确认整个目录都应删除后，应该怎么做？

用 rm -r mydir 用 rm -rf mydir 用 rmdir --force mydir

Q3: 你发现一个脚本文件 deploy.sh，ls -l 显示权限为 -rw-r--r--。你执行 ./deploy.sh 时报 "Permission denied"。为什么？

文件内容有语法错误 没有执行权限（x） 没有读权限（r）

Q4: 部署脚本里有这样一行：mkdir -p /app/logs/nginx。其中的 -p 是什么作用？

设置目录权限（permissions） 如果父目录不存在，自动创建 打印每一步的创建过程
