文本处理三剑客

grep 搜索、sed 编辑、awk 切分——部署脚本里处理文本的三件兵器

部署脚本经常需要文本处理：grep ERROR app.log | tail -20 查错误、sed 生成修改后的文本、awk '{print $1}' access.log | sort | uniq -c 统计列值。本课先掌握高频接口；遇到复杂格式、转义或多层状态时，优先使用结构化格式及其专用解析器。 
         ┌──────┐     ┌──────┐     ┌──────┐
 文件 →  │ grep │ →  │ sed  │ →  │ awk  │ → 结果
         │ 搜索  │     │ 替换  │     │ 切分  │
         │ 筛选行 │     │ 改内容 │     │ 提取列 │
         └──────┘     └──────┘     └──────┘
          搜索文本      编辑文本      分析文本

1. grep：从文本中筛选行

可以用 “global regular expression print” 记忆 grep 的历史来源。给它一个模式和输入，它输出匹配行；没有匹配时返回状态 1，这在条件判断中通常是正常结果。

grep ERROR /var/log/app.log          # 输出所有包含 ERROR 的行
grep -i error /var/log/app.log       # -i：忽略大小写（Error、ERROR、error 都匹配）
grep -v DEBUG /var/log/app.log       # -v：反向——输出不包含 DEBUG 的行
grep -r "deprecated" ./src/           # -r：递归搜索目录下所有文件
grep -n "panic" app.log              # -n：显示行号
grep -c ERROR app.log                # -c：只输出匹配行数（不输出内容）

三种正则口味：基本、扩展、Perl

grep   "a\|b"      # 基本正则（默认）：| 和 + 需要反斜杠转义
grep -E "a|b"      # 扩展正则（推荐）：|、+、(、) 可以直接用
grep -P "\d{3}"    # Perl 正则：支持 \d、\w、\s 等（部分系统不支持）

# 日常使用建议：-E（扩展正则）是甜点位置
grep -E "ERROR|FATAL|PANIC" app.log                        # 匹配三种级别
grep -E "[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}"   # 仅匹配 IPv4 外形，不校验 0-255
grep -E "2026-07-2[2-5] .*ERROR" app.log                   # 日期范围 + ERROR

grep 在部署脚本里的典型用法

# 1. 安静模式——只关心"有没有找到"，不关心输出内容
if grep -q "STARTED" /var/log/app.log; then
    echo "应用已启动"
fi

# 2. 按名称查进程；pgrep 比 ps | grep 更少误匹配
pgrep -af nginx                         # 选项在 BSD/macOS 上不同，先查本机手册

# 3. 只看匹配内容本身（-o = only-matching）
echo "Version: 3.14.2" | grep -oE "[0-9]+\.[0-9]+\.[0-9]+"
3.14.2

# 4. 显示匹配行的上下文（-B 前、-A 后、-C 前后）
grep -C 2 ERROR app.log   # 显示 ERROR 行及其前后各 2 行
grep 最常和管道配合。 先 grep 筛选出感兴趣的行，然后传给 sed 或 awk 做进一步处理，最后可能再用一个管道传给 sort/uniq/wc——这就是经典的"管道处理链"。

2. sed：流编辑器——改内容

sed 是流编辑器（stream editor）。它逐行读取文本，按指令转换后输出；替换是最常见的入门操作。

核心命令：s（替换）

sed 's/旧/新/'    # 每行替换第一个匹配
sed 's/旧/新/g'   # 每行替换所有匹配（g = global）
sed 's/旧/新/2'   # 每行只替换第二个匹配
echo "hello hello hello" | sed 's/hello/hi/'
hi hello hello           # 只替换了第一个

echo "hello hello hello" | sed 's/hello/hi/g'
hi hi hi                 # 全部替换

echo "hello hello hello" | sed 's/hello/hi/2'
hello hi hello           # 只替换第二个

分隔符不一定是 /

替换内容本身含斜杠时，换一个分隔符：

echo "/opt/app/bin" | sed 's/\/opt\/app/\/usr\/local/'
#                          ↑ ↑ 一堆反斜杠，眼花

echo "/opt/app/bin" | sed 's|/opt/app|/usr/local|'
#                          ↑ 用 | 做分隔符，清爽

# 可选择方便的单字节分隔符：s#旧#新#、s@旧@新@、s,旧,新,

-i：原地修改文件

sed -i 's/port=80/port=8080/' config.ini   # 直接修改文件（小心！）
sed -i.bak 's/port=80/port=8080/' config.ini  # 改前备份为 config.ini.bak
BSD/macOS 与 GNU sed 的 -i 接口不同。脚本若要跨平台，优先把输出写入同目录临时文件，验证成功后再替换；如果明确限定 GNU 环境，也可以声明并检查 GNU sed 依赖。不要只凭操作系统名称猜实现。

更高级的 sed（需要时再查，现在知道存在就行）

# 指定行范围：只在第 3 到第 5 行做替换
sed '3,5s/foo/bar/' file

# 按模式匹配行范围：从 START 到 END 之间的行做替换
sed '/START/,/END/s/foo/bar/' file

# 删除匹配的行
sed '/^#/d' config.ini            # 删除所有注释行
sed '/^$/d' config.ini            # 删除所有空行

# 在匹配行后追加
sed '/\[server\]/a port=8080' config.ini

3. awk：列处理器——切分和计算

awk 是一门记录与字段处理语言。先掌握按列筛选和聚合，再按实际需求查数组、函数和控制流。

核心模型：每行自动切成列

echo "alice  developer  85000" | awk '{print $1}'
alice                              # $1 = 第 1 列

echo "alice  developer  85000" | awk '{print $1, $3}'
alice 85000                       # $3 = 第 3 列，逗号 = 空格分隔

echo "alice  developer  85000" | awk '{print $NF}'
85000                             # $NF = 最后一列

echo "alice  developer  85000" | awk '{print $0}'
alice  developer  85000           # $0 = 整行
awk 默认按任意空白（空格/Tab）切分——连续的空格不会产生空列。这种"智能切分"是 awk 最方便的地方，你在 Python 里写 line.split() 才能得到同样的效果。

改变分隔符：-F

echo "alice:developer:85000" | awk -F: '{print $2}'
developer                        # -F: 用冒号做分隔符

grep "^[^#]" /etc/passwd | awk -F: '{print $1, $7}' | head -3
root /bin/zsh
daemon /usr/sbin/nologin
bin /usr/sbin/nologin            # 用户名 + Shell 类型

awk 在部署脚本里的典型模式

# 模式 1：提取特定列
df -h | awk '{print $5, $6}'      # 磁盘使用率 + 挂载点
ps aux | awk '{print $2, $11}'   # PID + 命令

# 模式 2：按条件筛选行（awk 内置 if 能力）
df -h | awk '$5+0 > 80'            # 只用磁盘使用率 > 80% 的行
#         $5+0：把 "85%" 转成数字 85（+0 强制数值转换）

awk -F: '$3 >= 1000 {print $1}' /etc/passwd  # 按示例阈值筛 UID；用户分类策略因系统而异

# 模式 3：计算——求和、求平均、计数
awk '{sum += $3} END {print sum}' data.txt        # 第 3 列求和
awk '{sum += $1; count++} END {print sum/count}'  # 第 1 列平均值

awk 的完整能力可以写一本书——它有变量、循环、函数、数组。但对于部署脚本，你只需要上面这些。 看到更复杂的 awk 用法时，把它理解成"一个在管道里处理列的小程序"即可。

4. 组合三剑客：经典的管道处理链

# 场景：分析 Nginx 访问日志，找出请求量 Top 5 的 IP
awk '{print $1}' /var/log/nginx/access.log \
    | sort \
    | uniq -c \
    | sort -rn \
    | head -5

# 场景：检查磁盘使用率，列出将要满的挂载点
df -h | awk 'NR>1 && $5+0 > 80 {print $6, $5}'
#         NR>1：跳过第一行（表头）

# 场景：统计每种错误的数量
grep -Eo "(Error|Warn|Fatal) [A-Za-z]+" app.log \
    | awk '{print $2}' \
    | sort | uniq -c | sort -rn

5. 三元对照：什么时候用哪个？

你的需求 用这个 写法
找包含 ERROR 的行 grep grep 'ERROR' file
把配置文件的 old 改成 new sed sed -i 's/old/new/' file
提取日志第 3 列（IP） awk awk '{print $3}' file
统计匹配行数 grep -c grep -c 'ERROR' file
删除空行和注释行 grep -v grep -vE '^#|^$' file
按冒号分隔取第 1、第 5 列 awk -F: awk -F: '{print $1, $5}' /etc/passwd
过滤 ps 输出的特定进程 grep ps aux | grep '[n]ginx'（巧妙的"不匹配自己"写法）

动手练习（5 分钟）

先创建测试数据，然后逐条试验三剑客的用法：

# 创建模拟日志
cat > /tmp/sample.log << 'EOF'
2026-07-27 10:01:23 INFO  Server started on port 8080
2026-07-27 10:02:15 ERROR Connection refused from 192.168.1.100
2026-07-27 10:02:16 WARN  Retry attempt 1 for 192.168.1.100
2026-07-27 10:02:17 ERROR Timeout from 10.0.0.55
2026-07-27 10:03:01 INFO  Request handled in 45ms
2026-07-27 10:03:45 ERROR Connection refused from 192.168.1.100
2026-07-27 10:04:00 FATAL Out of memory: process killed
2026-07-27 10:04:30 INFO  Health check passed
EOF

# === grep 练习 ===
grep ERROR /tmp/sample.log                          # 只看 ERROR 行
grep -c ERROR /tmp/sample.log                       # 统计 ERROR 数量
grep -E "ERROR|FATAL" /tmp/sample.log                # ERROR 或 FATAL
grep -v INFO /tmp/sample.log                         # 排除 INFO 行

# === sed 练习 ===
sed 's/ERROR/!!ERROR!!/' /tmp/sample.log             # 高亮 ERROR
sed 's/192\.168\.1\.100/192.168.1.200/g' /tmp/sample.log  # 替换 IP

# === awk 练习 ===
awk '{print $1, $2, $3, $5}' /tmp/sample.log         # 提取日期时间级别+消息碎片
awk '$3 == "ERROR" {print $0}' /tmp/sample.log       # 筛选 ERROR 行
awk '{print $3}' /tmp/sample.log | sort | uniq -c    # 统计每种级别出现次数

# === 经典组合技 ===
grep -E "ERROR|FATAL" /tmp/sample.log \
    | awk '{print $NF}' | sort | uniq -c | sort -rn

总结

│              文本处理三剑客 速查                            │
│                                                          │
│  grep — 搜索行       sed — 改内容        awk — 切分列    │
│                                                          │
│  grep PAT file          sed 's/old/new/'   awk '{print $1}'
│  -i  忽略大小写          s/old/new/g     全局  $0     整行

│  -r  递归搜索           -i.bak    改前备份  $NF   最后一列
│  -n  显示行号           /PAT/d     删除行   NR    行号
│  -c  只计数                                            │
│  -E  扩展正则                                          │
│  -q  安静（只判退出码）     分隔符可换：s|old|new|       -F:    冒号分隔
│  -o  只输出匹配部分                                    │
│                                                          │
│  管道经典链：grep → awk → sort → uniq -c → sort -rn → head │
└──────────────────────────────────────────────────────────┘

快速自检

Q1: 你想统计 app.log 里包含 "timeout"（忽略大小写）的行数。正确命令是？

grep -i -c timeout app.log grep -v timeout app.log | wc -c grep timeout app.log | awk '{count++} END {print count}'

Q2: sed 's/foo/bar/' 和 sed 's/foo/bar/g' 的区别是？

没有区别，"g" 只是风格习惯 前者每行只替换第一个 foo，后者替换该行所有的 foo 前者是文本替换，后者是正则替换

Q3: 下面这行输出是什么？ echo "a:b:c:d" | awk -F: '{print $NF}'

a a:b:c:d d

Q4: 要把配置文件里所有 host=localhost 改成 host=db.internal 并直接保存，命令是？

sed -i 's/host=localhost/host=db.internal/' config.ini sed 's/host=localhost/host=db.internal/' > config.ini grep -l 'host=localhost' config.ini | sed -i 's/host=localhost/host=db.internal/'
