# 学习工作区

`learning/` 保存需要长期维护的学习使命、课程安排、课件、课程专用练习、资料索引和学习证据。这里不是独立实验、
外部源码、构建输出或临时笔记的收集目录。

## 单个学习工作区

每个主题只维护一个当前使命，使用以下最小结构：

- `MISSION.md`：为什么学习，以及可以观察的成功表现。
- `CURRICULUM.md`：顺序、时间预算、任务和检查标准。
- `RESOURCES.md`：经过筛选的一手资料和可提供实践反馈的社区。
- `NOTES.md`：不会被前三个文件替代的稳定教学规则；不保存每日活动流水。
- `lessons/`：短课和即时反馈材料。
- `exercises/`：仅在课程确需可执行练习时创建；每项练习带离线检查。
- `learning-records/`：非显然认识、先验能力及其证据范围；不是逐课活动流水，不能仅凭标题推定当前掌握。

案例、速查资料、Anki 卡片和阶段成果只在确有需要时增加，不创建空目录占位。课程代码与其他目录的分界统一见
[仓库架构](../docs/project/architecture.md)。

## 恢复学习

1. 先读主题的 `README.md` 和 `MISSION.md`，确认目标仍然有效。
2. 查看 `learning-records/` 的证据范围，再用当前课程的最小迁移题抽样，不因课件或记录存在就假定已经学会。
3. 按 `CURRICULUM.md` 找到下一项未通过的检查，并运行上次保存的最小验证命令。
4. 课程专用短练习放 `exercises/`；其余可复现实现进入 `labs/`、`packages/` 或 `tools/`，不要复制两份。
