# 学习工作区

各主题 README 是恢复学习的唯一入口；跨主题背景与偏好见 [PROFILE.md](PROFILE.md)。

| 主题 | 当前方向 | 入口 |
| --- | --- | --- |
| Go | 从必要语言基础到独立交付后端 | [Go](go/README.md) |
| Bash | 日常自动化、失败边界与受管子进程清理 | [Bash](bash/README.md) |

每个主题仅要求 `README.md`，集中保存目标、当前状态、下一步、必要资料和检查命令。`exercises/`、`reference/`
和 `learning-records/` 按实际需要增加，不预制整套课件或目录。记录只保存真实表现、重要纠正及证据边界，材料存在、
教师演示或一次测试通过不等于独立掌握。

恢复时先读画像和主题 README，再按需查看证据与代码，一次推进一个具体问题。Agent 维护记录，不要求学习者另写
总结；画像修改仍需用户逐项确认。课程练习与其他目录的分界见[仓库架构](../docs/project/architecture.md)。
