# 已确认基础与课程方向

学习者有 Python 后端经验，简要了解 Go 语法但尚不熟练；目标是求职、技术储备和独立构建 Go 后端服务。
课程不再为学习目的虚构长期产品：leetgo 负责语言与 CLI 实践，Dagu 负责实际使用及后端、调度和分布式执行，
Nuclei 只负责补充高并发网络程序的比较学习；从零开发保留为短小、可测试的能力实验。

## Evidence

学习者明确否决了没有现实需求的 leetgo 记录服务、只读市场数据工具和 Miniflux，并确认 Dagu 有后续使用价值。

## Implications

后续课程应跳过 Python、HTTP 和 SQL 入门解释，把时间用于 Go 特有的值语义、错误、并发、资源生命周期、
测试、真实源码修改和后端失败处理。是否达到 10/20/35/50 小时里程碑必须由实际产出判断。
