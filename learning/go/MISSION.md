# Mission: 精通 Go 并独立交付后端服务

## Why

利用已有 Python/Django 后端经验，建立可用于求职、技术储备和个人项目的 Go 能力：不仅能写新服务，
还能读懂、诊断和修改真实 Go 工程。精通 Go 是长期必须完成的目标；课程用真实表现而不是累计课时判断进度。

## Success looks like

- 约 10 小时：能用 Go 1.26.5 独立完成小程序、测试和诊断，解释值语义、接口、错误和基本并发行为。
- 约 20 小时：能追踪 leetgo 的主要命令，并完成一项先复现、后测试、再实现的可评审修改。
- 约 35 小时：能实际使用并追踪 Dagu 的本地执行与 HTTP 路径，从零实现含 PostgreSQL 事务、有限后台任务、
  API、测试和优雅退出的后端切片。
- 约 50 小时：能诊断 Dagu 的队列、取消和 gRPC worker 行为，完成真实项目修改，并用 Nuclei 比较大型网络
  程序的并发与资源管理。
- 50 小时后：持续通过真实维护、故障诊断、代码评审和独立服务迭代，把本课程范围内的精通扩展到长期精通。

## Constraints

- 总学习投入先按 10–50 小时设计；每次 20–50 分钟，无固定节奏，任务必须能中断和恢复。
- 固定使用 Go 1.26.5；案例固定 tag、commit 和代码路径，不跟随浮动分支。
- leetgo 用于语言和 CLI 工程实践；Dagu 用于后端与系统工程；Nuclei 只作为高并发网络程序的比较案例。
- 课程优先使用 Go 官方资料、固定版本源码、项目官方文档和可复现实验；第三方项目的局部写法不自动成为通用建议。
- 每次源码学习必须产生调用说明、失败复现、测试、代码修改或测量结果之一。

## Out of scope

- 为课程虚构长期产品、市场数据工具、交易系统或 leetgo 运行记录服务。
- 未经授权扫描公网目标、执行真实资金交易、保存私钥或接触生产凭证。
- 在核心 50 小时内深入 ORM、Kafka、Redis、Kubernetes、复杂前端或大规模分布式一致性算法。
- 重讲已经掌握的 Python、HTTP 和 SQL 入门知识，或横向背诵大量框架 API。
