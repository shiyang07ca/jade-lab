# 790. 多米诺和托米诺平铺

用两个状态记录完整面板和缺角面板，即可逐列计算铺法数量。L 形瓷砖会留下不整齐的边界，因此只记录完整矩形还不够。

- [题面](python/question.md)
- [Python 解法及注释](python/solution.py)
- [本地用例](python/testcases.txt)

## 状态定义

- `full[i]`：铺满 `2 × i` 完整面板的方法数。
- `gap[i]`：铺满 `2 × i` 面板**去掉右上角格子**后的方法数，其余格子都必须覆盖。

去掉右下角的方案与去掉右上角的方案可以通过上下翻转一一对应，因此数量相同。
`gap[i]` 只统计一种朝向，不是两种朝向之和。

以下列号从 1 开始，`i` 表示最右一列。

## 缺角面板的转移

缺右上角时，最右一列只剩右下角。覆盖这个格子的瓷砖只有两种放法：

1. 横向多米诺：覆盖第 `i - 1` 列下格和第 `i` 列下格。移除它后，剩下宽度为 `i - 1`、缺右下角的面板，方案数为 `gap[i - 1]`。
2. L 形瓷砖：覆盖第 `i - 1` 列的两个格子和第 `i` 列下格。移除它后，剩下宽度为 `i - 2` 的完整面板，方案数为 `full[i - 2]`。

两种情况互不重复，且覆盖所有可能：

```python
gap[i] = gap[i - 1] + full[i - 2]
```

## 完整面板的转移

根据右端的瓷砖分类：

| 右端铺法 | 移除后剩余形状 | 方案数 |
| --- | --- | --- |
| 最后一列放一块竖向多米诺 | 宽度为 `i - 1` 的完整面板 | `full[i - 1]` |
| 最后两列放两块横向多米诺 | 宽度为 `i - 2` 的完整面板 | `full[i - 2]` |
| L 形瓷砖覆盖最后一列两格，并伸入前一列一格 | 宽度为 `i - 1` 的缺角面板 | `2 * gap[i - 1]` |

第三项乘 2，因为 L 形瓷砖伸入前一列的格子可以在上方，也可以在下方。

如果 L 形瓷砖只覆盖最后一列的一格，它就必须占据前一列的两格，导致最后一列的另一格无法合法覆盖。因此这种摆放不会出现在完整铺法中。

三类互不重复，也没有遗漏，所以：

```python
full[i] = full[i - 1] + full[i - 2] + 2 * gap[i - 1]
```

## 边界与示例

```python
full[0] = 1
full[1] = 1
gap[0] = 0
gap[1] = 0
```

空面板有一种铺法——什么都不放。这让“放完一块瓷砖后恰好没有剩余”计为一种方案。
宽度为 1 的完整面板只能放一块竖向多米诺；缺角面板只剩一个格子，无法覆盖。
`gap[0]` 仅为占位边界，本实现不会用到它的转移。

| 宽度 `i` | `gap[i]` | `full[i]` |
| --- | --- | --- |
| 1 | 0 | 1 |
| 2 | `0 + 1 = 1` | `1 + 1 + 2 × 0 = 2` |
| 3 | `1 + 1 = 2` | `2 + 1 + 2 × 1 = 5` |
| 4 | `2 + 2 = 4` | `5 + 2 + 2 × 2 = 11` |

每次计算对 `10**9 + 7` 取模；加法和乘法允许在中间取模，不改变最终余数。
每个状态只计算一次，时间复杂度为 `O(n)`，两个数组的空间复杂度为 `O(n)`。
