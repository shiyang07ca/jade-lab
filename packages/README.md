# Packages

`packages/` 只保存由其他代码直接导入、链接或声明为依赖的软件包。每个一级子目录是一个能够独立构建和测试的
发布单元，名称描述它提供的能力，而不是笼统地按语言归档代码。

一个模块进入这里前必须同时满足：

1. 已有明确的代码调用场景，README 能指出使用方和解决的问题。
2. 只有一个有意设计的公开接口；使用方不需要了解内部目录和实现细节。
3. 输入限制、返回值、可观察副作用和错误类型明确。
4. 测试从公开接口调用，覆盖正常路径、重要边界和主要错误。
5. 能构建成该语言通常使用的依赖单元，例如 Python wheel、Go module、Java artifact 或原生库。
6. 在 `modules.toml` 中标记为 `stable` 并加入默认检查。

当前模块：

- [`python-algorithms/`](python-algorithms/)：用于算法复习和题解原型的 Python 软件包。

仅展示语法的程序、单文件题解、未验证片段和只有命令行入口的程序不属于 `packages/`。由人、CI 或定时任务
直接运行的程序进入 `tools/`；为了回答一个问题而保留的实现进入 `labs/`。原 C++、Go、Java 与未晋升的 Python
源码均保留在 [`labs/`](../labs/) 的 `algorithms/` 或 `languages/` 模块，没有移入 `.scratch/`。
