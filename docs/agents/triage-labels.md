# Triage Labels

技能用五个标准分类角色表达意图。本文件把这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此票据                        |
| `needs-info`               | `needs-info`         | 等待报告者补充信息                         |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可供 AFK agent 处理              |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                               |
| `wontfix`                  | `wontfix`            | 不会处理                                   |

当技能提到某个角色（例如"应用 AFK-ready 分类标签"）时，使用本表中对应的标签字符串。

如需修改右列以匹配实际使用的词汇，直接编辑本文件。
