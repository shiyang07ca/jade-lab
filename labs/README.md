# Labs

`labs/` 保存为了回答明确技术问题而需要独立依赖、可执行代码和重做命令的实验。实验可以不稳定，但必须如实说明
当前能证明什么、不能证明什么；保留价值来自可重做的问题和观察结果，而不是目录名称。

二级目录按问题领域组织，例如 `algorithms/`、`databases/`、`languages/`、`networking/` 和 `storage/`；三级目录
才是独立模块。语言机制程序放 `languages/`，算法实现研究放 `algorithms/`，不要再建立 `examples/`、`cookbook/`
或按“其他”归档的目录。

实验出现稳定调用方式后再迁移：被其他代码依赖的部分进入 `packages/`，由人或自动化系统重复执行的程序进入
`tools/`。迁移只移动已经验证的实现，其余有学习价值的代码继续留在原实验，不需要删除或放入 `.scratch/`。
